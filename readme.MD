# Calc Project Document

This repository hosts a comprehensive, self-contained Calc project document that serves as an educational reference guide covering all major spreadsheet features. The guide is written in a structured, example-driven format, making it an ideal learning resource for anyone looking to build practical spreadsheet skills from the ground up.

## Getting Started

If you are new to spreadsheets, start with the **Introduction** chapter, which covers core Calc concepts, the spreadsheet interface, and establishes the sample dataset used throughout the guide:

- **[Start Here — Introduction to Calc](docs/calc-guide/00-introduction.md)**

### Prerequisites

- Basic computer literacy (file management, keyboard and mouse usage)
- A Calc or spreadsheet application installed (such as LibreOffice Calc or any compatible spreadsheet program)

### Recommended Reading Approach

- **Beginners:** Read the chapters sequentially starting from the Introduction. Each chapter builds on concepts introduced in earlier sections.
- **Experienced users:** Jump directly to a specific topic using the table of contents in the [Full Documentation](docs/README.md) for targeted reference.

## What's Covered

This guide covers the following spreadsheet topics with clear explanations, practical examples, and step-by-step calculations:

- **Spreadsheet data organization** — structuring, labeling, and organizing data effectively
- **Formulas: SUM and AVERAGE** — aggregating and summarizing numeric data
- **Formulas: IF and VLOOKUP** — conditional logic and data lookup operations
- **Pivot tables** — dynamic data summarization, grouping, and analysis
- **Charts and data visualization** — creating and customizing visual representations of data
- **Financial analysis** — financial functions including PMT, FV, PV, NPV, and IRR
- **Data validation** — input controls, dropdown lists, and error alerts
- **Conditional formatting** — rule-based cell formatting, color scales, data bars, and icon sets
- **Quick reference and formula cheat sheet** — consolidated syntax reference, keyboard shortcuts, and error code guide
